Biography

I hold a BSc in Electrical and Electronic Engineering (CGPA 3.78/4.00, Cum Laude).

Graduate study goals. Projects

Glucose and wearable signal analysis: preprocessing, features and short-term prediction

In progress
View on GitHub · Python, NumPy, Pandas, scikit-learn, Jupyter

A personal research project using a public CGM/wearable dataset from PhysioNet to practise the pipeline I want to use in graduate research: cleaning noisy physiological time series, extracting features, and building short-term glucose prediction models against simple baselines, with participant-wise evaluation. Preliminary work; results will be posted in the repository.

  • Data quality handling. Missing values, sensor dropout, timestamp alignment.
  • Signal preprocessing. Artefact removal, resampling, filtering.
  • Feature extraction. Glucose variability, time-in-range, activity and heart-rate window features.
  • Modelling. Persistence and linear baselines vs. a tree-based model for 30-minute prediction, evaluated with participant-wise splits (RMSE/MAE).

ECG signal processing and beat classification on open PhysioNet records

Planned
View on GitHub · Python, SciPy, NumPy, scikit-learn, WFDB

A study project to build an end-to-end ECG pipeline on publicly available annotated records, from raw waveform to beat-level classification. The aim is to work directly with the filtering, detection and validation steps that underpin clinical signal analysis.

  • Preprocessing: baseline wander removal, powerline notch filtering, bandpass design.
  • QRS detection and beat segmentation from annotated reference records.
  • Morphological and interval features, including RR-interval series.
  • Baseline classifiers evaluated with record-wise splits to avoid leakage between beats of the same patient.

Heart rate variability and sleep/activity patterns from open wearable data

Planned
View on GitHub · Python, Pandas, SciPy, Matplotlib, Jupyter

A project to extract heart rate variability and daily activity rhythm measures from public wearable datasets, and to examine how preprocessing choices change the resulting features. The focus is on reproducible feature definitions rather than on any single model.

  • Interbeat interval cleaning, ectopic beat handling and resampling.
  • Time-domain and frequency-domain HRV features over sliding windows.
  • Actigraphy-based rest/activity segmentation and daily rhythm summaries.
  • Sensitivity analysis: how window length and artefact thresholds affect feature stability.

Reimplementing my undergraduate J–V quantum dot solar cell model in Python

Planned
View on GitHub · Python, NumPy, SciPy, Matplotlib, Jupyter

A port of the analytical J–V model from my undergraduate thesis and conference paper from MATLAB to an open Python notebook. The goal is to make the numerical work reproducible and openly inspectable, and to document the model assumptions in one place.

  • Reimplementation of the analytical current–voltage model, including series resistance and load voltage.
  • Parameter sweeps over dot density, bandgap and absorber width.
  • Numerical validation against the figures published in the original paper.
  • Documented notebook so the derivation and code can be read together.
